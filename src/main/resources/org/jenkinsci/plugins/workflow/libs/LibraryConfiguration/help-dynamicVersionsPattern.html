A regular expression (matched against the whole string) that a dynamically resolved revision must satisfy to be used, when it was discovered via ${BRANCH_NAME}, ${env.VARNAME}, or their CHANGE_BRANCH/CHANGE_TARGET pull request fallbacks. A revision rejected by this pattern falls back to the configured default version, exactly as if it had not resolved at all.
This does not apply to a fixed, literal version string written by the pipeline author (e.g. @Library('libname@somebranch')).
Defaults to ^.*$ (allow anything). Consider narrowing this down if dynamically resolved revisions could otherwise be steered by someone who can influence a branch name or environment variable but should not be able to pick arbitrary library versions.
